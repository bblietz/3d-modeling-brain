# Woodworking stock and design rules

Starting values from general reference, in the same locked-constants
spirit as [[lego-geometry]]: change only with measured evidence. Nothing
here has been verified against Brian's actual stock or tools yet. After
each furniture build, promote measured values (actual sheet thickness,
real kerf, joint fits that worked) into this note via the retrospective.

**The one rule that overrides every number below: measure the actual
stock before cutting any joinery sized to it.**

## Sheet goods

| Stock | Nominal | Typical actual | Note |
|---|---|---|---|
| Plywood 3/4" / 18mm | 18mm | 17.5-18.2mm | Varies by batch; measure |
| Plywood 1/2" / 12mm | 12mm | 11.5-12.2mm | |
| Plywood 1/4" / 6mm | 6mm | 5.2-6.0mm | Back panels; thinnest batches near 5mm |
| MDF | as labeled | close to nominal | Heavier, weaker screw-holding |
| Standard sheet | 2440 x 1220mm (8 x 4 ft) | | Yield-check parts against this |

## Solid lumber (US nominal vs actual, dry dimensional)

| Nominal | Actual (mm) |
|---|---|
| 1x2 | 19 x 38 |
| 1x3 | 19 x 64 |
| 1x4 | 19 x 89 |
| 1x6 | 19 x 140 |
| 2x2 | 38 x 38 |
| 2x4 | 38 x 89 |

Common board lengths: 1830 / 2440 / 3050mm (6 / 8 / 10 ft).

## Cutting and fits

- Saw kerf: assume 3mm for layout/yield checks until measured.
- Dado / groove: cut to MEASURED stock thickness; test cut in scrap
  first. A snug dado needs no clearance number, it needs a test cut.
- Sliding fit (removable shelf in a housing): ~+0.5mm.
- Drawer box in opening: ~1mm gap per side, ~1mm top.
- These are starting values; replace with measured results from
  retrospectives in [[learnings]].

## Wood movement

- Solid wood moves across the grain (roughly 1% of width seasonally,
  species-dependent); it barely moves along the grain.
- No rigid cross-grain attachment over ~150mm: use slotted screw holes,
  buttons, or figure-8 fasteners (tabletops, wide solid panels).
- Plywood and MDF are dimensionally stable; this rule is for solid wood.

## Practicality

- Interior doorway clear width: ~750mm. Anything wider or deeper must be
  knock-down or assembled in place.
- Counter height ~720mm, desk ~735mm, seat ~450mm, bookshelf depth
  ~250-300mm: useful defaults when the user has no constraint.
