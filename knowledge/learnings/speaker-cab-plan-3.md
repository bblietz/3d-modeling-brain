## Design-level items for Brian

- The bridge is strict on ported boxes (flat serves tight, punchy serves balanced, boomy serves big only) and the site box reads punchy with every catalog speaker, so a tight target always proposes: both dry runs produced tone-driven boxes past the bridge word (30.0 L and 33.4 L, both punchy), never the site box. A tolerance on the bridge is Brian's call.
- The `port mouth` warn fires on the site box's own rear tube, on every 1x12 front slot whose floor needs a stiffener, on slots in shallow boxes, and on most 2x12 slot boxes at their default depth: both fixtures kept one. Coverage is reported but no threshold gates the warn; decide whether a coverage threshold or a deeper default box should quiet it.
- `--fb` is uncapped in code; only the voicing note binds the skill to the engine's 45 to 90 Hz range.
- The port loop changes the port type and the box size after stop one (rex: a rear 153.2 mm tube in 482 x 434 x 267 mm approved, a front slot in 475 x 463 x 252 mm built). The skill now re-presents the provisional port lines at stop two; the alternative is to run the plain `cab.py` layout before stop one so the loop closes on the sheet Brian approves.
- A combo's extension jack puts the cabinet in parallel with the combo's own speaker (8 || 16 = 5.3 ohm, 8 || 8 = 4 ohm on an 8 ohm winding); the engine's mismatch check reads the cabinet alone, so the combined load is a prose fact in the Rig block and `rig_and_goals`, never a sheet or proposal fact.
- `propose` with `--port-tube` and a non-default `--port-diameter` silently prefers the tube; the plan lists five input errors and this is not one.
