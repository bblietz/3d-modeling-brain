## What was built

- **Architecture.** Astro 4.16.19 stays static except `/quote/*`, which `@astrojs/cloudflare` 11.2.0 renders per request with `output: "hybrid"` (plan Decision 1). `functions/api/quote.ts` is retired (Cloudflare ignores `functions/` once `_worker.js` exists), and its Turnstile and Resend code moved to `src/lib/quote-delivery.ts`. `src/middleware.ts` with `src/lib/security-headers.ts` applies the `public/_headers` CSP plus `Cache-Control: private, no-store` to worker responses (drift test, 3 tests). Drafts live in KV `QUOTE_DRAFTS` under `draft:<uuid>` with a 1209600 s TTL on every put, found by the `mc_draft` cookie (path `/quote`, HttpOnly, Secure, SameSite=Lax, 14 days) or a `?d=` link. Nothing is written on GET (`/quote/start?line=` only redirects). Local bindings are in `wrangler.dev.toml`. All request logic is plain TypeScript under `src/lib/wizard/`; pages only translate a `WizardResult`.
- **Data contract (Task 3).** `src/lib/quote-options.ts` (12 option sets, `CABINET_PREFILL`). `src/lib/quote-schema.ts` (22 tests): per-step schemas composed into `QuoteSchema`, one primary-amp predicate and message. `src/lib/quote-summary.ts` (8 tests): `quoteSections()`, the ten Rig block sections in the brief's order (Order, Amps, Guitars, Pedals, Music and use, Tonal goals, Physical, Connections, Aesthetics, Speaker), shared by the review page and the email. `src/lib/email-template.ts` (7 tests): blanks read `(not asked)`, continuation lines indented.
- **Flow and drafts (Tasks 4 to 6).** `steps.ts` (11 tests): nine steps, with primary-amp shown only for two or more amp lines. `draft.ts` (10 tests): `findDraft`, load, save, delete, and `mergeStep`, which clears a stale finish, Where it lives, and primary amp. `form.ts` (6 tests): FormData per step, CRLF to LF. `submit.ts` (10 tests): safety-net `QuoteSchema`, then Turnstile, Resend, and delete. `handle-step.ts` (29 tests): deep link, resume, restart notice, in-order gate, edit routing, storage failures. `quote-delivery.ts`: 12 tests. Final state at e5fa9d2: 155 tests in 14 files (147 at 404518c, plus `result.test.ts` for the cookie helper, three `findDraft` id tests, and a `checkOrigin` build check), `npm run check` 0 errors, build complete.
- **Pages and components (Tasks 2, 7 to 9).** `src/pages/quote/[step].astro` and `index.astro`. 14 components under `src/components/wizard/`: WizardFrame, TextInput, ChoiceGroup, SelectInput, SwatchChoices, eight step components, and ReviewStep (ten sections, each with an Edit link, a contact fieldset with an h2, Turnstile). Reveals are CSS-only through Tailwind `group-has-[...]`, and the wizard has no JavaScript of its own (the only scripts are Turnstile on review and the site analytics beacon). 16 Mojotone swatches (8 tolex, 8 grill cloth) are hosted under `public/materials/`, replacing seven retired images, with the shortlists in the content collection. Both product pages link to `/quote/start?line=<slug>`; `QuoteForm.astro` is deleted.
- **Delivery hardening (38bb396, 8632400, ec646af, a58236b).** Failures log the message and error only, and tests assert no token or email in the logs. `verifyTurnstile` returns false (403, "spam check did not pass") only for the routine codes `missing-input-response`, `invalid-input-response`, and `timeout-or-duplicate`; a non-2xx reply or any other code throws (logged, 502 retry). `sendQuoteEmail` throws with the status and Resend's error name only. `SEND_FAILED`, `LOAD_FAILED`, and `SAVE_FAILED` are each defined once and offer bblietz@gmail.com. A KV load or save failure re-renders the step with a 503; a delete failure after a sent quote still redirects to `/thanks`. Name and phone reject line breaks ("Keep it on one line"). Draft identity: `?d=` first, then a different cookie id, at most two reads; the cookie is set only on a POST redirect carrying a draft id (decided by the pure `draftCookieUpdate` helper in `result.ts`); a `role="status"` notice offers "start a new quote" when a product page's line differs from the saved draft's. Astro's `security.checkOrigin` (34c36b5) rejects any non-GET without a matching `Origin` (cross-site form POSTs, HEAD, Origin-less POSTs) with a bare text 403.
- **Security lockdown (be62906).** `image.endpoint` points at `src/image-endpoint.ts` (a GET returning 404) with `passthroughImageService()` kept, and `routes.extend.exclude` lists `/_image`. The build test asserts that the effective routes equal `["/quote/*"]`, that exclude holds `/_image`, and that the worker has no `loadRemoteImage`. The adapter still lists `/_image` in include, but Cloudflare applies exclude first. The controller re-verified on 404518c: both `/_image` probes return 404, `loadRemoteImage` is in 0 worker files, GET renders send no Set-Cookie, and a cabinet POST returns 303 with the cookie. Re-verified on e5fa9d2: 155 tests in 14 files, and no worker file contains the loader.
- **Vault (Task 10, d43a494).** 1 file, 24 insertions, 6 deletions; pushed 52a3f45..d43a494 per [[reference-vault-github-repo]] and verified with `git ls-remote`. `skills/speaker-cab/SKILL.md` Phase 1 now reads the wizard email: the first line carries name, email, and any phone; ten blocks follow in the brief's order, one row per field; amps arrive as `Amp 1`, `Amp 2` with `(primary)`; the finish row reads `Tolex color` or `Wood species`; continuation lines are indented; Driver count reads `1x12` or `2x12`. `(not asked)` on a 1x12's Jack configuration row or a tolex cab's Where it lives row means the field does not apply. ## What worked and what to change next time

- The pre-flight scan paid off. Thirteen findings were settled before Task 2, and running Tasks 3 to 6 in a scratch copy proved the amended plan executes. Regenerate task briefs after any plan amendment.
- The review loop kept surfacing plan-mandated or decision-mandated issues (Tasks 3, 6, 8, the Turnstile escalation, the final review's five decisions). Batching them as questions to Brian while unaffected tasks kept running (Task 9, and the vault's Task 10 beside Task 8) kept the work moving.
