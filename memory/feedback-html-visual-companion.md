When a question or explanation is visual (shape options, geometry variants, cross-sections, layouts), show it in an HTML page, such as the brainstorming visual companion or a published Artifact with to-scale SVG drawn from the CAD geometry. Do not put ASCII art in AskUserQuestion previews or chat.

**Why:** On 2026-09-12, during the [[project-leader-cards]] slot design, Brian was shown ASCII side-section and top-view sketches for slot hitch, wave edge, and lead-in choices and said "instead of using ASCII art, always use an HTML based visual companion".

**How to apply:** Before asking any visual design question, build or update the HTML page first, then ask the question in text pointing at it. Drawings should come from the real model geometry where one exists, per [[feedback-agentic-os-conventions]].

**Update 2026-09-26 (desk cable storage):** after three text questions Brian said "Instead of asking all of these questions in text, start drawing them up and show them to me. I am very much a visual person." Ask at most one or two scoping questions, then build the to-scale scene, render the options in place, push the page, and ask against the pictures. Fold the remaining questions (material, size, position) into the drawings as variants or callouts instead of asking them in text.
