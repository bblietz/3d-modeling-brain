2. Flow of data

The geometry file is the hub: decisions enter as named constants, every part is modeled once, and all deliverables are emitted from the same PARTS registry so the cut list cannot drift from the model. Exports are gated by environment variables on the same run.

3. Architecture

Three things talk to each other: the Claude Code session (main thread plus subagents), the vault, and the runtime that turns Python into geometry you can see. The vault is the source of truth; the two symlinks make its skills and memory the ones the session loads.

4. The /furniture phases

What each phase takes in, what it must produce before the next may start, and the tooling behind it. The ordering is load-bearing: joinery is decided in Phase 2 because it changes part lengths, and the cut list cannot be right before that.

5. The Drawer-bench in numbers

Size convention option (a): 36 x 24 in is the top; the posts sit inside a 1-1/4 in overhang, so the footprint is 33-1/2 x 21-1/2 in and the drawer opening between the posts is 27-1/2 in; height 20 in. Soft maple posts and rails, plywood panels and drawer boxes, a laminated top, 18 in Blum-class undermount slides. About 49 kg, clears a 750 mm doorway with 140 mm to spare.

Where the CAD forced a value the prose had not closed

Each is a single constant in the file, and each is waiting on Brian's review; the asserts flag any knock-on clash when one moves.

  • Top drawer opening 4-1/2 in; boxes 3-11/16 and 8-11/16 in at Blum's maximum, 14 mm above their rails (top box interior about 69 mm)open
  • Three stopped mortises per front post instead of a continuous front-frame groove, so the slide tabs land on solid postopen
  • Rear top rail (1-1/2 in) tenoned into the back groove line; back panel 15-1/4 in tall beneath itopen
  • Rails milled to the measured ply thickness (T18) so their stub tenons fill the 3/8 in grooves; the cut list prints 11/16 in as a consequenceopen
  • Bottom panel's front edge in a 1/4 x 1/2 rabbet run through the bottom rail's tenons; panel notched around all four postsopen
  • 7 mm ply lip under the bottom groove in sides and back; lowering the groove stop to 1 in would give 20 mm (owner's call)open
  • Assembly order with the bottom pre-joined to the back off the bench; every part enters by a straight sideways moveopen

Run it: EXPORT=1 TMP_STL=$SCRATCH/db.stl .venv/bin/python projects/Drawer-bench/drawer_bench.py from the vault root; add SHOW=reset for the first viewer push and SHOW=1 after each edit. Nothing is cut until the space, the Boos island and both plywood thicknesses are measured and the file re-run.
